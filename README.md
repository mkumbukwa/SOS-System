# SOS-System
Emergency SOS System ni mfumo wa usaidizi wa dharura unaowawezesha watumiaji kutuma tahadhari (SOS) kwa haraka kwa kutumia simu au kompyuta. Mfumo huu una features kama kitufe cha SOS kinachofungua simu kupiga au kutuma SMS kwa namba za dharura, sehemu ya kuhifadhi contacts muhimu kama familia na marafiki, pamoja na ramani inayoonyesha
